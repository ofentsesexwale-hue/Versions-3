# Beneficiary file table of contents

This is the office **table of contents** for a beneficiary file. Staff photograph
or file papers in this order.

Official Word originals:

- Index: [`dsd-source/Content_Page.docx`](dsd-source/Content_Page.docx)
- Supervisor Yes/No evidence sheet: [`dsd-source/NPO_Check_List.docx`](dsd-source/NPO_Check_List.docx)
- Scan of the filled contents page (guide): `beneficiary-file-contents.png`

Field-level inventory: [`WORD_TEMPLATES.md`](WORD_TEMPLATES.md).

`NPO_case_management_file.pdf` is a **guide** for how these papers sit in a
file. Do not overlay it. Print/scan geometry for sheets already in the atlas
still comes from PDF-derived PNGs until Word fill is rebuilt.
