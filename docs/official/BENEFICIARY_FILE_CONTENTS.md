# Beneficiary file table of contents

This is the office **table of contents** for a beneficiary file. Staff photograph or file papers in this order. The scan is `beneficiary-file-contents.png` (same sheet: practitioner name, date, Yes/No evidence, comments, practitioner signature).

Official DSD Word/Excel originals for the CW and COW sheets sit in [`dsd-source/`](dsd-source/). They are **reference only** until a later pass builds an atlas page for that sheet. Do not invent a substitute form when the original is here.

Print/scan geometry for sheets already in the atlas still comes from `NPO_case_management_file.pdf` and `backend/core/form_atlas.py`.
